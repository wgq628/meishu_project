# TEMPLATE.md Reference

> Copy of the canonical report template at `memory/analysis/TEMPLATE.md`.
> Load this when helping another Agent craft an analysis report for the kunlun-output-packaging skill.

## Structure

The template contains these sections:

1. **元信息** — YAML metadata (title, date, confidence)
2. **问题框架** — Problem framing with safety gate #1 output
3. **分析方法** — Discipline tree + information processing summary
4. **系统结构** — OCGS boundary, keys, circuits, base patterns, emergence
5. **多维透视** — 3-lens table (efficiency/structure/power)
6. **外部视角** — Best-minds expert views, collision points, corrections
7. **战略判断** — Stage positioning, criteria, cross-stage prediction
8. **核心结论** — Finding cards with confidence/evidence/failure conditions
9. **抽象产物** — Abstracted patterns + fork decision log
10. **未闭合议题** — Open issues
11. **跨域交叉校验** — Cross-domain comparison table (for second+ instance)
12. **交付检查清单** — The 8-item delivery checklist
