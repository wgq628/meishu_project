## 1.3 哲学统筹机制

多桥共振的产出在汇聚到OS层后，经过三次哲学过滤：

```
步骤1 — 矛盾论统摄（确定主次）
  问：当前共振发现中，哪个是主要矛盾？
  答：主要矛盾确定后，其他发现围绕它组织，不分散

步骤2 — 实践论检验（验证可行性）
  问：这个规律在现实中有反例吗？能否操作化？
  答：不能通过实践检验的 → 标注"待验证"，不视为结论

步骤3 — 历史唯物主义校准（价值过滤）
  问：这个方案符合生产力的发展方向吗？
  答：不符合最广大人民利益的 → 降级或否决
```

## 1.4 产出分级

经过哲学统筹后，所有共振产出分为三级：

| 级别 | 标记 | 条件 | 去向 |
|---|---|---|---|
| **结论级** | ✅ | 通过全部三步哲学检验 | T2命题→MEMORY.md |
| **假设级** | ⚠️ | 逻辑自洽但未通过实践论检验 | T3→memory-index，标注"待验证" |
| **噪音级** | 🗑️ | 逻辑不自洽或与事实矛盾 | 丢弃，不记录 |
