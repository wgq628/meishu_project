# 元认知协议 — Metacognitive Protocol

> 创建于安装日 | 昆仑系统
> 周期性自检与认知节律。

---

## 自检八项

每次深度分析完成后，执行以下检查：

- [ ] ① 复杂度判定是否正确（轻载/深度选择是否合理）
- [ ] ② 入口框架是否显化（前提假设是否被检查）
- [ ] ③ 安全闸#1-#3是否全部通过
- [ ] ④ 学科桥决策树是否产生（P0/P1是否明确）
- [ ] ⑤ 知识源声明是否完整（所有判断是否标注信度等级）
- [ ] ⑥ 数据置信度标注是否到位
- [ ] ⑦ 反例测试是否执行
- [ ] ⑧ 抽象化萃取是否产出可复用洞察

## 认知节律

- **每会话**：加载今日记忆文件
- **每个深度分析**：执行自检八项
- **每重大产出**：成果封装流程
